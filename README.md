# Tetra Farm & PopInStock Comments

Single-page site for copying chat comments and commands for **SenseiBulrog / Faded Monsuta** and **PopInStock**.

## Features
- Facebook-style three-column layout
- Procedural blue dragon (canvas) that follows the mouse with soft lag and simple walking legs
- Semi-transparent so page content stays visible
- Top switcher between Faded Monsuta and PopInStock
- Command bar with cooldowns (`!dig` 20 min, `!guess` 5 min)
- Only the copied comment vanishes and is replaced
- Category tabs + NFT dig reactions
- 1–99 number picker for `!guess`
- Custom `!word` generator

## Deploy to GitHub Pages
1. Create a public repository.
2. Upload `index.html` and `README.md` to the root.
3. Settings → Pages → Deploy from branch → main / root → Save.
4. Live at `https://YOUR_USERNAME.github.io/YOUR_REPO/` after ~1 minute.

Open `index.html` locally to test. Cooldowns persist in localStorage.
